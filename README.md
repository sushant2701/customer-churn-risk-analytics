# Customer Behavior Analytics & Churn Risk System

A machine learning powered analytics web application built with Python (Flask), Scikit-learn,
Pandas, and Chart.js that predicts customer churn risk and segments telecom customers
based on behavioral and billing patterns.

## Overview
This project processes 50,000+ telecom customer records through a complete ETL pipeline —
resolving nulls, removing duplicates, and normalizing features — before applying optimized
SQL segmentation queries and a Random Forest classification model to identify high-risk
churn customers with 85% prediction accuracy.

## Key Features
- End-to-end ETL pipeline with live logging of each data cleaning step
- Optimized SQL queries with indexed joins for customer segmentation by usage and billing tier
- Random Forest churn prediction model with Precision, Recall, and F1-Score evaluation
- Risk dashboard with KPI cards, churn trend charts, and top 20 high-risk customer table
- Excel export of flagged high-risk customer list with churn probability scores

## Tech Stack
Python · Flask · SQLite · Pandas · Scikit-learn · Chart.js · Bootstrap 5 · OpenPyXL

## Skills Demonstrated
ETL · Data Cleaning · SQL Query Optimization · ML Classification · Feature Engineering ·
Trend Identification · Stakeholder Reporting · Churn Analysis · Risk Segmentation

## Use Case
Mirrors real-world customer analytics workflows used by telecom and retail data teams
for retention strategy and revenue protection decisions.
